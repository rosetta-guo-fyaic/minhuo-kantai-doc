# 客户运行与监控目录说明

## 1. 目录定位

`CUST-客户标识/` 用于承接某个客户上线后的持续运行与监控事实。

---

## 2. 建议承载内容

1. `00_客户运行总览.md`
2. `01_系统监控配置.md`
3. `02_运行记录/YYYY-MM/`

## 4. 使用规则

1. 本目录下的日常运行记录必须按时间持续沉淀。
2. 运行记录、巡检、告警和操作日志建议按月归档。
3. 严重运维事件应转入 `04_运维问题处置/`。
