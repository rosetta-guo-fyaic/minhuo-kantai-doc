# 月度运行记录目录说明

## 1. 目录定位

`YYYY-MM/` 用于承接某个客户在某个月内的运行与监控记录。

---

## 2. 建议承载内容

建议优先形成：

1. `YYYY-MM_巡检与监控记录.md`
2. `YYYY-MM_告警处理记录.md`
3. `YYYY-MM_运维操作日志.md`
4. `YYYY-MM_运行状态观察.md`

---

## 3. 对应工具仓库入口

1. 模板：
   - `<TOOL_REPO_ROOT>/07_公共模板库/06_四号仓库模板/02_系统运维模板/11_运行记录模板.md`
2. AI 能力：
   - `<TOOL_REPO_ROOT>/08_AI工作站/01_AI能力模块/06_四号仓库能力模块/AM-07_系统运维编排器.md`

---

## 4. 使用规则

1. 月度目录应只记录当月事实。
2. 日常运行记录和事件复盘不要混写；重大事件应转入 `04_运维问题处置/`。
