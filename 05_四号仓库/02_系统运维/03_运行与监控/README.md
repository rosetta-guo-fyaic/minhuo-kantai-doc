# 运行与监控说明

## 1. 目录定位

`03_运行与监控/` 用于承接客户系统的持续运行状态、监控配置、巡检记录、告警处理和运维操作日志。

它是运维岗位的日常运行观察区。

---

## 2. 组织方式

本目录应按客户组织，并在客户目录下按时间持续记录。

固定结构建议：

```text
03_运行与监控/
├── 00_运行与监控总览.md
└── CUST-客户标识/
    ├── 00_客户运行总览.md
    ├── 01_系统监控配置.md
    └── 02_运行记录/
        └── YYYY-MM/
```

---

## 3. 建议承载内容

建议优先形成：

1. 系统监控配置
2. 巡检记录
3. 告警处理记录
4. 运维操作日志
5. 运行状态观察

## 5. 使用规则

1. 客户目录下的运行记录必须按时间持续沉淀。
2. 监控配置和运行日志应分开记录，不要写在同一份文档里。
3. 本目录记录运行事实和日常操作，不替代事故处置与复盘。
4. 若运行中发现严重问题，应转入 `04_运维问题处置/`。
