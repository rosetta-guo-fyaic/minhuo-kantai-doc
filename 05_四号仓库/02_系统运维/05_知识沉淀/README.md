# 运维知识沉淀说明

## 1. 目录定位

`05_知识沉淀/` 用于把运维工作中已经稳定、可复用的经验沉淀成长期资产。

它不记录单次事件本身，而负责提炼方法和经验。

---

## 2. 建议承载内容

建议优先形成：

1. 常见问题处置手册
2. 故障排查路径
3. 监控与告警经验
4. 部署与升级经验库

---

## 3. 对应工具仓库入口

1. 规范：
   - `<TOOL_REPO_ROOT>/06_工作规范/08_发布与运维规范/`
2. 模板：
   - `<TOOL_REPO_ROOT>/07_公共模板库/06_四号仓库模板/02_系统运维模板/`
3. AI 能力：
   - `<TOOL_REPO_ROOT>/08_AI工作站/01_AI能力模块/06_四号仓库能力模块/AM-07_系统运维编排器.md`

---

## 4. 使用规则

1. 仅当内容具备复用价值时，才进入本目录。
2. 单次事件原始记录应保留在 `04_运维问题处置/`。
3. 本目录中的方法应可被后续运维快速复用，而不是只描述过去发生过什么。
