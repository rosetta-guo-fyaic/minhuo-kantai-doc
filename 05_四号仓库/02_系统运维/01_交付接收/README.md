# 交付接收说明

## 1. 目录定位

`01_交付接收/` 用于承接版本级运维交付接收动作。

它是运维岗位正式接过某个版本部署责任的起点。

---

## 2. 组织方式

本目录必须按版本组织。

固定结构建议：

```text
01_交付接收/
└── vX.Y.Z/
    ├── 00_版本交付接收总览.md
    ├── 01_版本安装包与制品清单.md
    ├── 02_部署与升级手册.md
    ├── 03_回滚与恢复说明.md
    └── 04_运维接收确认记录.md
```

---

## 3. 建议承载内容

每个版本目录建议至少承接：

1. 安装包、镜像、脚本、制品清单
2. 部署步骤和升级步骤
3. 回滚条件与恢复路径
4. 运维接收结论
5. 交付缺口与阻断项

## 5. 使用规则

1. 交付接收必须以版本为对象，不得把多个版本混在一份记录里。
2. 若版本交付物不完整，应显式记录缺口，不得默认“先接了再说”。
3. 本目录只负责“接收版本交付物”，不记录客户实际部署事实；客户部署事实进入 `02_环境与部署/`。
