# 版本交付接收目录说明

## 1. 目录定位

`vX.Y.Z/` 用于承接某个具体版本进入运维接收时的正式交付材料。

2. `01_版本安装包与制品清单.md`

4. `03_回滚与恢复说明.md`
5. `04_运维接收确认记录.md`

## 4. 使用规则

1. 本目录只承接版本级交付接收材料，不记录客户实际部署事实。
2. 客户实际部署和环境变化，应进入 `02_环境与部署/`。
3. 若版本交付物不完整，应在本目录显式记录缺口和阻断项。
