# 运维总览说明

## 1. 目录定位

`00_运维总览/` 是系统运维线的总入口。

它用于让运维岗位快速回答以下问题：

1. 当前系统整体运维范围是什么。
2. 已进入运维接收的版本有哪些。
3. 当前有哪些客户和环境在运行。
4. 产品总体部署架构是什么。
5. 当前有哪些待办和风险。

---

## 2. 建议承载内容

建议优先形成：

1. `00_系统运维总览.md`

## 4. 使用规则

1. 产品整体部署架构应放在本目录，不应散落在单客户或单环境记录中。
2. 本目录负责“全局看板”，不替代后续具体交付接收、部署、运行和事件处置记录。
3. 若客户、环境、版本状态发生变化，应同步回写本目录中的总表和总览。
