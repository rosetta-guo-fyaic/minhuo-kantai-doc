# 运维问题处置说明

## 1. 目录定位

`04_运维问题处置/` 用于承接突发运维问题、系统事故、性能故障和运维事件复盘整改。

它按事件组织，不按客户拆分。

## 4. 使用规则

1. 这里记录的是事件本身，而不是环境说明或环境变更。
2. 若事件涉及某个客户或环境，可在正文中引用对应对象，不必先按客户建目录。
3. 事故处置完成后，应补复盘和整改结论。
4. 若事件中沉淀出可复用经验，应回写 `05_知识沉淀/`。
