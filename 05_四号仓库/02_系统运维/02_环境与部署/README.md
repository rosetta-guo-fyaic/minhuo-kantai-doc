# 环境与部署说明

## 1. 目录定位

`02_环境与部署/` 用于承接客户级环境事实、部署动作、升级动作和环境变更记录。

它回答的是：

1. 某个客户有哪些环境。
2. 每个环境当前运行什么版本。
3. 某次部署、升级、热修复是怎么做的。
4. 环境本身发生过哪些变更。

---

## 2. 组织方式

本目录应优先按客户和环境组织。

固定结构建议：

```text
02_环境与部署/
├── 00_环境与部署总览.md
└── CUST-客户标识/
    ├── 00_客户部署总览.md
    ├── ENV-PROD_生产环境.md
    ├── ENV-UAT_验收环境.md
    ├── ENV-TRAIN_培训环境.md
    ├── REL-001_首次部署记录.md
    ├── REL-002_vX.Y.Z升级记录.md
    ├── REL-003_hotfix部署记录.md
    └── CHG-ENV-001_环境变更记录.md
```

---

## 3. 建议承载内容

建议优先形成：

1. 环境说明
2. 部署记录
3. 升级记录
4. 热修复部署记录
5. 环境变更记录

## 5. 使用规则

1. 环境对象优先于版本对象。
2. 同一客户的不同环境必须分开记录，不得在一份文档中混写。
3. 涉及环境、资源、配置的变更，应记录在本目录。
4. 纯事故、故障和应急处置，不进入本目录，应进入 `04_运维问题处置/`。
