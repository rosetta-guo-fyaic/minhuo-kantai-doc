## 4. 使用规则

1. 本目录下的运营记录必须按时间持续沉淀。
2. 数据监控与效果跟踪应放在运营记录中，不再单独平行拆出。
3. 若出现突发运营问题或客户使用事故，应转入 `04_运营问题处置/`。
