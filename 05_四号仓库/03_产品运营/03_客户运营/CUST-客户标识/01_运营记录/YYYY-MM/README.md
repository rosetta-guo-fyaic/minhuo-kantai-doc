# 月度运营记录目录说明

## 1. 目录定位

`YYYY-MM/` 用于承接某个客户在某个月内的运营事实。

---

## 2. 建议承载内容

建议优先形成：

1. `YYYY-MM_运营操作日志.md`
2. `YYYY-MM_数据监控与效果跟踪.md`
3. `YYYY-MM_客户支持记录.md`
4. `YYYY-MM_阶段运营分析.md`

---

## 3. 对应工具仓库入口

   - `<TOOL_REPO_ROOT>/07_公共模板库/06_四号仓库模板/03_产品运营模板/09_数据跟踪与分析模板.md`

---

## 4. 使用规则

1. 月度目录应只记录当月事实。
2. 日常支持与阶段分析应在本目录沉淀。
3. 若发生重大运营异常或事故，应转入 `04_运营问题处置/`。
