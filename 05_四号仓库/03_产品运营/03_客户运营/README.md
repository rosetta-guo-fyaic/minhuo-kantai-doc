# 客户运营说明

## 1. 目录定位

`03_客户运营/` 用于承接客户上线后的持续运营记录。

它按客户组织，并在客户目录下按时间持续沉淀运营事实。

---

## 2. 组织方式

固定结构建议：

```text
03_客户运营/
├── 00_客户运营总览.md
└── CUST-客户标识/
    ├── 00_客户运营总览.md
    └── 01_运营记录/
        └── YYYY-MM/
```

---

## 3. 建议承载内容

按时间记录：

1. 运营操作日志
2. 数据监控与效果跟踪
3. 客户支持记录
4. 阶段运营分析

## 5. 使用规则

1. 日常客户运营和数据跟踪统一放在本目录，不再平行拆出单独的数据目录。
2. 运营记录必须按时间持续沉淀。
3. 若出现突发运营问题或事故，应转入 `04_运营问题处置/`。
