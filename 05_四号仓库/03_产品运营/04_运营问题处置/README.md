# 运营问题处置说明

## 1. 目录定位

`04_运营问题处置/` 用于承接突发运营问题、客户使用事故、运营异常和运营复盘整改。

它按事件组织，不按客户拆分。

## 4. 使用规则

1. 本目录承接的是运营事件本身，不记录日常支持流水。
2. 若事件涉及具体客户，可在正文中引用客户对象，不必先按客户建目录。
3. 事件处置完成后，应补复盘和整改结论。
4. 若沉淀出可复用方法，应回写 `05_知识沉淀/`。
