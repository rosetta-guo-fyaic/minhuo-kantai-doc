# 运营知识沉淀说明

## 1. 目录定位

`05_知识沉淀/` 用于把运营工作中已经稳定、可复用的经验沉淀成长期资产。

它不记录单次运营事件本身，而负责提炼经验和方法。

---

## 2. 建议承载内容

建议优先形成：

1. 常见问题处理手册
2. 角色支持经验库
3. 客户上线经验库
4. 运营优化经验库

---

---

## 4. 使用规则

1. 仅当内容具备复用价值时，才进入本目录。
2. 单次运营事件原始记录应保留在 `04_运营问题处置/`。
3. 本目录中的经验应面向后续运营快速复用，而不是只复述历史事件。
