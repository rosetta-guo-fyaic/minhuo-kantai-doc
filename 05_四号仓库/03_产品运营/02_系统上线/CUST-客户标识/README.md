## 4. 使用规则

1. 本目录记录的是运营视角的客户上线过程，不替代技术部署记录。
2. 技术部署与升级事实应在系统运维目录同步沉淀。
3. 上线完成后，持续运营活动应转入 `03_客户运营/`。
