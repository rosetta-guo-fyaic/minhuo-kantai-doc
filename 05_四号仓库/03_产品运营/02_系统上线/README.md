# 系统上线说明

## 1. 目录定位

`02_系统上线/` 用于承接客户上线与启用过程中的准备、执行和确认记录。

它关注的是运营视角的“客户启用”，不是技术部署动作本身。

---

## 2. 组织方式

本目录应按客户组织。

固定结构建议：

```text
02_系统上线/
├── 00_系统上线总览.md
└── CUST-客户标识/
    ├── 00_客户系统上线总览.md
    ├── 01_环境启用说明.md
    ├── 02_培训与宣导计划.md
    ├── 03_初始化准备清单.md
    ├── 04_上线执行记录.md
    └── 05_上线确认记录.md
```

## 4. 使用规则

1. 每个客户应独立记录上线与启用过程。
2. 技术部署动作进入系统运维目录，本目录只记录运营视角需要承接的上线过程。
3. 上线完成后，后续持续支持应转入 `03_客户运营/`。
