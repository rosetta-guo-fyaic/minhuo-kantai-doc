# 运营总览说明

## 1. 目录定位

`00_运营总览/` 是产品运营线的总入口。

它用于让运营岗位快速回答以下问题：

1. 当前支持哪些客户。
2. 哪些客户处于上线初期、稳定运行或重点支持阶段。
3. 当前运营重点、风险和待办是什么。

---

## 4. 使用规则

1. 本目录负责“运营全局看板”，不替代后续客户上线、客户运营或运营问题处置记录。
2. 若客户状态或当前支持重点发生变化，应同步回写本目录。
