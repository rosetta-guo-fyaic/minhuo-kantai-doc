# 测试报告目录说明

## 1. 目录定位

`05_测试报告/` 用于输出当前版本的阶段性或最终测试结论报告。

这里回答的是：

1. 当前版本整体测试情况如何。
2. 覆盖范围、问题数量、风险状态是什么。
3. 是否具备进入下一阶段的条件。

---

## 2. 建议内容

建议至少包括：

1. `REP-001_阶段测试报告.md`
2. `REP-002_回归测试报告.md`
3. `REP-003_验收测试报告.md`
4. `REP-004_版本交付测试报告.md`

说明：

1. 可按测试阶段输出多份报告。
2. 最终版本交付前应至少有一份可对外或对项目组使用的正式测试报告。

## 4. 编写规则

1. 测试报告应基于正式执行记录、Bug 状态和验收结论汇总形成。
2. 报告中应明确风险，不得用口头结论替代书面记录。
3. 若存在带病交付事项，应在本目录和 `06_版本放行与交付建议/` 中同时体现。
