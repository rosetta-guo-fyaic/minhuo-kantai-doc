# 测试设计目录说明

## 1. 目录定位

`01_测试设计/` 用于沉淀当前版本的正式测试设计产物。

这里回答的是：

1. 这个版本测什么。
2. 为什么这样测。
3. 用哪些用例覆盖范围。
4. 哪些内容本轮不测或延后测。

---

## 2. 建议内容

建议至少包括：

1. `00_测试范围与策略说明.md`
2. `01_测试用例总表.md`
3. `02_模块测试用例/`
4. `03_专项测试设计/`

说明：

1. 模块测试用例可按模块拆分。
2. 专项测试可覆盖接口、权限、兼容性、性能、回归等。

## 4. 编写规则

1. 测试设计必须以二号仓库当前版本产品基线为准。
2. 若涉及技术约束或非功能边界，应引用三号仓库技术方案。
3. 测试项应能追溯到产品需求、页面、流程、规则或接口。
4. 不应在这里记录执行结果，执行结果应进入 `02_测试执行/`。

---

## 5. 一句话规则

**这里定义“本版本怎么测”，不记录“已经测成什么样”。**
