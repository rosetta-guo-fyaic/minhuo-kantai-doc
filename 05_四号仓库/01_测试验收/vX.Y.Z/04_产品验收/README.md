# 产品验收目录说明

## 1. 目录定位

`04_产品验收/` 用于沉淀产品经理、业务方或验收责任人在当前版本上的正式验收过程与结论。

这里回答的是：

1. 验收按什么范围进行。
2. 验收过程发生了什么。
3. 验收发现了哪些问题。
4. 最终是否验收通过。

---

## 2. 建议内容

建议至少包括：

1. `00_验收计划与范围说明.md`
2. `01_验收清单.md`
3. `UAT-001_验收执行记录.md`
4. `02_验收结论与待整改项.md`

## 4. 编写规则

1. 验收范围应以产品基线和版本测试结果为基础。
2. 验收问题若属于已知 Bug，应引用 `03_Bug管理/` 中的对应问题单。
3. 验收结论应明确“通过 / 有条件通过 / 不通过”。
4. 放行建议需同步进入 `06_版本放行与交付建议/` 汇总。
