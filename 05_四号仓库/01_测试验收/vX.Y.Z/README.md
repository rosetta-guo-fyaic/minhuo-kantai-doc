# 版本测试验收目录说明

## 1. 目录定位

`vX.Y.Z/` 用于承接某个具体版本的完整测试与验收执行产物。

该目录中的内容应与以下上游对象保持一致：

1. 二号仓库产品基线 `vX.Y.Z`
2. 三号仓库当前版本技术方案

---

## 2. 子目录说明

1. `01_测试设计/`：当前版本测试范围、策略、用例设计
2. `02_测试执行/`：当前版本多轮测试执行记录与证据
3. `03_Bug管理/`：当前版本缺陷、回归与遗留风险
4. `04_产品验收/`：当前版本验收过程与结论
5. `05_测试报告/`：当前版本测试报告与汇总结论
6. `06_版本放行与交付建议/`：当前版本放行判断与交付约束

---

## 4. 使用规则

1. 一个版本只建一个版本目录。
2. 不同版本之间不得混放测试记录、Bug 或验收记录。
3. 若当前记录已不属于本版本，应回流版本治理链路，而不是继续留在本目录中。
