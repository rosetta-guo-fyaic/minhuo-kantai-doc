# Bug 管理目录说明

## 1. 目录定位

`03_Bug管理/` 用于沉淀当前版本测试与验收过程中发现的缺陷、回归与遗留风险。

这里回答的是：

1. 当前版本发现了哪些问题。
2. 问题严重程度和影响范围是什么。
3. 修复后是否完成回归。
4. 是否存在遗留缺陷与已知风险。

---

## 2. 建议内容

建议至少包括：

1. `BUG-001_*.md`
2. `BUG-002_*.md`
3. `REG-001_*.md`
4. `00_遗留缺陷与风险清单.md`

说明：

1. 单个缺陷建议单文档记录。
2. 回归记录可按轮次或按缺陷集合记录。

## 4. 编写规则

1. Bug 必须归属当前版本，且可追溯到测试执行或产品验收记录。
2. 若问题本质属于环境、部署或运行问题，应回到运维链路处理，不要误记为产品缺陷。
3. 若问题本质属于需求口径错误，应回流二号仓库。
4. 遗留缺陷必须明确是否阻断放行。
