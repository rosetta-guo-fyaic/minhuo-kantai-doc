# 版本放行与交付建议目录说明

## 1. 目录定位

`06_版本放行与交付建议/` 用于沉淀当前版本最终是否建议放行、交付或延期处理的正式意见。

这里回答的是：

1. 当前版本是否可以放行。
2. 放行前还有哪些阻断项。
3. 是否存在带病交付事项。
4. 对交付和上线有什么限制条件。

---

## 2. 建议内容

建议至少包括：

1. `00_版本放行判断总览.md`
2. `01_阻断问题清单.md`
3. `02_带病交付说明.md`
4. `03_版本放行与交付建议.md`

## 4. 编写规则

1. 放行建议应综合测试执行、Bug 管理、产品验收和测试报告结论形成。
2. 阻断项应可追溯到具体缺陷、验收项或环境前提。
3. 带病交付必须明确影响范围、风险说明和后续跟进要求。
4. 若最终结论依赖客户环境准备情况，可引用系统运维与产品运营相关记录。
