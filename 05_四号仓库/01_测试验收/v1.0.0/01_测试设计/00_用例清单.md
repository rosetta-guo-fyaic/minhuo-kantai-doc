## 5. 环境与数据纪律（防污染）

| 项目 | 内容 |
|------|------|
| 种子库真源 | `minhuo-kantai-code/minhuo.db`（22 品类/56 规则/10 变化，init_db.sh 产物）——**测试全程只读**，执行前后校验和留痕 |
| 写操作隔离 | 接口层写用例：每用例 `cp minhuo.db → $TMP` 后以 `MH_DB_PATH` 指向副本（db.py 原生支持该环境变量，非硬编码）；界面层写流：服务实例以 `MH_DB_PATH=/tmp/qa_ui.db` 启动 |
| 库面直连测试 | sqlite3 直连 /tmp 副本（触发器/CHECK/事务回滚），不触碰种子库 |
| 空库实例 | `001_init.sql` 建 schema 不播种，`PORT=8010 MH_DB_PATH=/tmp/qa_empty.db` 起第二实例 |
| 恢复策略 | 全部临时库即用即弃；无需 init_db.sh 恢复（种子库从未被写）；仍以执行前后 sha256 留痕证明 |
