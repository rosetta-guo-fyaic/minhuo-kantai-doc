## 2. 技术形态定版

1. 原生 HTML5 + CSS + JavaScript（ES2017+，无框架、无 npm/Node、无打包器、无外部 CDN——全局方案 §6.1）。
2. 页面为静态文件，由 FastAPI 托管：`app.mount("/", StaticFiles(directory="frontend/static", html=True))`——**API 路由先注册、静态挂载最后**，`/api/*` 优先匹配。
3. 数据全部 `fetch('/api/...')` 获取，页面不含任何业务数据字面量；渲染为字符串模板 + `escapeHtml` 统一转义（总体方案 §7.2 XSS 防护）。

## 4. 公共 JS（`js/app.js`，五页共用）

## 5. 页面 × API 绑定（本件核心）

| 页面 | 区块 | API 调用 | FR | 交互要点 |
|------|------|----------|----|----------|
| PD-001 index.html | 卡片区 | `GET /api/overview?region&source_type&status` | FR-001 | 与筛选联动重算（FR001-R1）；空库三卡 0 |
| | 筛选区+列表区 | `GET /api/rules?granularity=merged&region&source_type&status` | FR-002/003 | 行=展示条目按 name_zh 排序；行展开渲染 sources[]（信源筛选时高亮所选信源行）；徽章/摘要 40 字/updated |
| PD-002 regions.html | 矩阵区 | `GET /api/regions/matrix` | FR-004 | 五行三列+合计；行点击高亮并加载下钻（空区可点） |
| | 下钻区 | `GET /api/regions/{code}/rules?source_type&status` | FR-005/003 | 未选大区显示引导语 EMPTY.guide（非空表）；source_display「合并（N 源）」/单源名；依据全文 |
| PD-003 changes.html | 时间线 | `GET /api/changes?category_id&region` | FR-006 | 倒序六要素（时间/品类/大区/旧→新徽章/信源·依据/操作者）；只读，无任何写入口 |
| PD-004 maintain.html | 登记表单 | `POST /api/rules` | FR-007 | 前端预校验（FORM.required/tooLong）；409 → dup 文案+「转修订」按钮定位该 existing_rule_id 行并展开修订面板 |
| | 规则列表 | `GET /api/rules?granularity=source&q&region&source_type` | FR-007 | 源规则逐行（含修订按钮），默认 -updated_at 排序 |
| | 修订面板（行内展开） | `PUT /api/rules/{id}` | FR-008 | 新状态预选当前态；422 → noChange 文案；200 → okRev 文案+PD-003 跳转链接 |
| PD-005 search.html | 搜索+结果 | `GET /api/search?q=` | FR-009/003 | URL `?q=` 预填自动执行；分组渲染 regions[]；truncated → tooMany 提示；空结果 → NO_HIT_TITLE/DESC |

每页脚本文件内联于页尾 `<script>`（5 页规模无需独立页面级 js 文件），但**只能**调用 app.js/constants.js 能力，不得复制其实现（单点纪律，Task-007 grep 验收）。

## 6. 无构建链部署与验收

1. 部署 = 文件存在于 `frontend/static/` 即完成；升级 = 覆盖文件 + 浏览器强刷（无缓存哈希，v1.0.0 本地单机可接受，留痕）。
2. 启动自检：`uvicorn app.main:app --port 8000` 后 `curl -s localhost:8000/ | grep 现状总览` 命中即托管正常。
3. 静态资源全部相对路径引用，离线可运行（无 CDN 探测）。
