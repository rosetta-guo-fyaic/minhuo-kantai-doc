# 跨模块专项说明

## 1. 目录定位

`03_跨模块专项/` 用于承接那些同时影响多个模块、但又不适合作为总体总则或单模块正文的专项技术设计。
这里默认承接外部提供接口、外部引用接口、系统集成、对账补偿和跨模块数据交换等边界型真源。

## 2. 主要承载内容

建议优先承接以下内容：

1. 跨模块流程编排或事务协同
2. 跨模块公共数据流转或同步机制
3. 对外提供接口设计
4. 对外引用接口设计
5. 系统集成、对账、补偿和联调规则
6. 共享领域服务、共享搜索、共享消息、共享缓存等公共能力专题
7. 多模块共同命中的专项风险与验证方案

建议优先形成的文件包括：

1. `01_外部提供接口设计.md`
2. `02_外部引用接口设计.md`
3. `03_系统集成与对账补偿设计.md`
4. `04_跨模块数据交换与同步设计.md`
5. `05_公共能力复用评估.md`
6. `06_系统依赖补充.md`
7. `07_降级策略专题.md`

## 3. 使用规则

1. 若某事项可以稳定归属到单个模块，优先回到 `02_模块技术方案/`。
2. 若某事项属于单个模块内部数据库落库或内部接口实现，不应放在本目录，应回到模块技术包。
3. 若某事项属于全项目统一规则，应优先回到 `01_总体技术方案/`。
4. 本目录不替代模块技术包，也不应成为“放不下就都扔进来”的兜底杂项区。
