# 产品路标说明

## 1. 目录定位

`04_产品路标/` 用于存放项目阶段计划、版本节奏、里程碑、路线图、偏差纠偏动作，以及全部正式版本的主控信息。

它负责把项目从“已启动”推进到“按什么节奏推进、每个阶段要达成什么、发生偏差后如何纠正”的治理状态。

## 2. 主要承载内容

建议优先形成以下内容：

1. 阶段计划
2. 版本节奏
3. 里程碑安排
4. 路线图说明
5. 偏差与纠偏动作
6. 当前版本、当前分支和历史版本卡

建议目录内按以下方式理解：

1. `00_版本总表.md`
   - 记录当前工作版本、当前工作分支、历史版本和规划版本
   - 是零号仓库版本总入口
2. `VER-vX.Y.Z_版本卡.md`
   - 保存在 `04_产品路标/` 根下
   - 每个版本一张卡，按正式版本逐步新增

## 3. 使用规则

1. 路标应与项目范围、需求优先级和资源安排保持一致
2. 重大节奏调整应显式记录，不应只在群消息中口头通知
3. 一号、二号、三号、四号仓库的阶段推进，均应能回看本目录中的路标口径
4. 若发布时间、关键依赖或里程碑发生变化，应优先回写本目录真源
5. 当前工作版本和当前工作分支，应以 `00_版本总表.md` 和对应 `VER-*` 为准
6. 一旦版本卡建立，版本号、分支名和上一版本不得修改
