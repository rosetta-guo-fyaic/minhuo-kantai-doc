# 项目环境说明

## 1. 目录定位

`02_项目环境/` 用于存放 Git、权限、账号、环境、协作工具、AI 插件和其他项目环境准备信息。

它负责确认项目是否具备进入正式协作和交付阶段的基础环境前提，并在环境发生变化时持续回写真源。

## 2. 主要承载内容

建议优先形成以下内容：

1. 协作工具与账号准备情况
2. 环境访问与权限说明
3. Git 与版本协作前提
4. 项目基础资源说明
5. AI 插件和项目级运行宿主状态

## 3. 使用规则

1. 环境和权限准备不到位时，不应默认项目可以顺利推进
2. 项目环境信息应尽量结构化，避免只靠口头交接
3. 若环境口径变化，应同步更新本目录主文件
4. 若工具仓库挂载、Skill 安装或项目级 `.claude/.agents` 状态变化，应同步更新本目录真源
