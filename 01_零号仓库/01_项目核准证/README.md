# 项目核准证说明

## 1. 目录定位

`01_项目核准证/` 用于存放项目核准、立项、范围确认、边界修订和基础准入信息。

它是零号仓库中最核心的启动准入真源区，用于回答“这个项目为什么做、做到哪里、由谁负责、当前以什么边界推进”。

## 2. 主要承载内容

建议优先形成以下内容：

1. 项目立项背景
2. 项目目标与范围
3. 适用边界与不适用边界
4. 关键准入约束
5. 边界变化与修订留痕

## 3. 使用规则

1. 若项目范围、主体边界、职责边界未明确，不宜直接进入正式正文仓推进
2. 同类启动结论应收口到本目录，不要散落在会议纪要和临时说明里
3. 后续若边界有重大变化，应显式修订本目录真源
