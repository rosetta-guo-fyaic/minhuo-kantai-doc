# 零号仓库 Agent 说明

## 1. 推荐读取顺序

1. 项目仓库根 `README.md`
2. `01_零号仓库/README.md`
3. `00_OD工作区/README.md`
4. `06_工作规范/03_项目管理规范/`
5. `07_公共模板库/02_零号仓库模板/`
6. `08_AI工作站/01_AI能力模块/02_零号仓库能力模块/`
7. 必要时补读 `04_标准词典库/` 与 `09_DIC研发方法论/`

## 2. 开始工作前必须确认

1. 当前工作区结构检查已通过。
2. 当前任务确实属于零号仓库。
3. 当前目标是项目启动、信息补录还是规范校对。

## 3. 允许输出

1. 项目核准类文件
2. 项目环境类文件
3. 需求池和范围清单
4. 路标和里程碑说明

## 4. 禁止越界事项

1. 不得提前输出一号仓库正式需求分析。
2. 不得提前输出二号、三号、四号仓库正式产物。
3. 不得在零号仓库中复制公共规范、模板或 AI 工作站正文。
