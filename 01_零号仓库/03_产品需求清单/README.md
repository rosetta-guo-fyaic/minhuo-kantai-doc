# 产品需求清单说明

## 1. 目录定位

`03_产品需求清单/` 用于存放产品需求池、首期范围、非首期范围、需求优先级、项目级回写状态，以及正式版本对应的项目级版本需求清单。

它负责在项目推进过程中持续维护项目级范围真源，而不是只在零号仓库启动阶段一次性登记。

## 2. 主要承载内容

建议优先形成以下内容：

1. 首期范围需求清单
2. 非首期范围登记
3. 需求优先级说明
4. 需求池调整记录
5. 来自一号仓库与二号仓库的回写状态
6. 各正式版本的项目级版本需求清单

建议目录内按以下方式理解：

1. `00_产品需求池.md`
   - 记录项目滚动产品需求池
   - 不按版本拆分
2. `VDL-vX.Y.Z_版本需求清单.md`
   - 记录单版本的项目级范围纳入与排除
   - 历史 VDL 文件应保留，不得覆盖旧版本

## 3. 使用规则

1. 这里是产品需求池，不替代一号仓库的正式需求分析结论
2. 首期和非首期范围应显式区分，避免后续需求扩散
3. 若需求优先级调整，应记录调整依据和影响范围
4. 一号仓库阶段结束后，应回写产品需求池与版本需求范围到本目录真源
5. 二号仓库在产品基线阶段引用本目录 `VDL-vX.Y.Z` 作为版本范围依据，不得脱离本目录独立发明
