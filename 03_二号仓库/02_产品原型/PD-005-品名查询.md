## 3. 区块说明

### 3.1 查询输入区（FR-009）

1. 单输入框 + 查询按钮；支持回车触发；支持 URL `?q=` 参数预填并自动执行（承接各页头部快捷搜索）。
2. 匹配口径（QL-005 定版）：对品类中文名/英文名做**双向子串包含匹配**（不区分大小写）；不做分词、不做同义词、不做推理。

### 3.2 结果区（FR-009 + FR-003）

1. 按品类分组：命中品类名高亮；每个品类下按大区列出展示条目（合并态 + 冲突徽标），结构与 PD-001 展开行一致。
2. 每个大区条目可再展开该组合全部源规则（信源+状态+依据）——「展示各状态规则及依据」（US-008 AT-001）。
3. 结果上限：单次命中品类 >50 时截断显示前 50 并提示「命中品类过多，请补充关键字」（防全库刷屏；阈值原型期取 50，四号仓库按此验收）。

### 3.3 无命中文案（QL-005 语义 + 全局方案 §3.3 视觉定版）

```text
未命中结构化规则
建议转关务人工判断。当前规则库无该品名的结构化规则，看台不做推理判定。
```

不返回模糊猜测、不展示「猜你想查」（GBR-006）。
