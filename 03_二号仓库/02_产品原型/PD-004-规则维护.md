## 3. 区块说明

### 3.1 登记表单区（FR-007）

1. 字段：品名中文*、品名英文*、大区*（五区下拉）、信源*（五源下拉）、状态*（三态下拉，默认「可接」）、依据*（多行文本）、备注（选填）、登记人*（文本）。
2. 新品类自动建档（同名中文或英文已存在则复用既有品类，不重复建档）。
3. 提交即生效（GBR-005）：成功后规则立即可见于 PD-001/002/005；表单不清空依据字段以外内容无需保留，提示「登记成功」。
4. 重复约束：同「品类×大区×信源」已存在 → 拦截提示「该品类在该大区×信源下已有规则，请改用修订」，提供「转修订」快捷入口（定位到该规则行并展开修订面板）。

### 3.2 规则列表区（FR-007/FI-008 共用）

1. 列：品类（中/英）、大区、信源、状态徽章、依据摘要、操作者、更新时间、操作（修订）。
2. 检索：品类关键字（中英包含匹配）+ 大区/信源下拉过滤。
3. 排序：默认更新时间倒序。

### 3.3 修订面板（FR-008）

1. 行内展开（非弹窗）：显示定位信息（品类/大区/信源）与当前状态；字段：新状态*（三态下拉，预选当前状态）、修订依据*（多行文本，不预填）、操作者*（文本）。
2. 确认校验：新状态与当前状态相同 → 提示「状态未变化，无需修订」，不产生变化记录（US-007 AT-003）。
3. 提交成功：规则状态/依据更新 → 自动追加变化记录（GBR-002）→ PD-001/002/005 即时切换口径；提示「修订成功，已自动生成变化记录」并附 PD-003 跳转链接。
4. 提交即生效，无审核流（QL-002）。

## 4. 异常与空态
