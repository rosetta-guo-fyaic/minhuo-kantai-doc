## 3. 区块说明

### 3.1 大区 × 状态矩阵（FR-004）

1. 行 = 五大区（EU/NA/ME/SEA/OTHER，固定顺序），列 = 三态 + 合计；格子数字 = 该大区展示条目按就严合并态计数（全局方案 §3.2：无信源筛选场景）。
2. 行可点击（整行或任一格子）；点击后下钻区切换为该大区明细，行高亮。
3. 空大区：格子显示 0，合计 0，仍可点击（下钻显示空态）。

### 3.2 大区下钻明细区（FR-005）

1. 默认（未选大区）：显示引导语「点击上方矩阵中的大区行，查看该大区规则明细」。
2. 选定大区后：展示该大区全部展示条目；行结构 = 展示条目（品类×大区合并态 + 冲突徽标），展开行显示各信源源规则；列含更新时间（规则 updated_at，展示 YYYY-MM-DD）。
3. 区内二次筛选：信源/状态，口径同 PD-001 §3.2（选定信源 → 条目状态 = 该信源状态）。
4. 不提供目的港级下钻（VDL 非范围；矩阵行即最细地区粒度）。
