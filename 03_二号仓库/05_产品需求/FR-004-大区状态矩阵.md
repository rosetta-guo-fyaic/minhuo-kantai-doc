## 1. 功能概述

### 1.0 来源追溯表

| 追溯维度 | 来源编号/章节 |

### 1.1 功能说明

分地区视图顶部展示五行（五大区）×三列（三态）+合计列的计数矩阵，格子数字=该大区展示条目按就严合并态的计数，行可点击进入下钻明细（FR-005），让用户一眼比较各市场风险面。

### 1.2 前置条件

规则库可访问。

### 1.3 功能范围

**包含**：矩阵渲染（固定五区三态）、计数、行点击与高亮、空区 0 显示。
**不包含**：目的港下钻（VDL 非范围，BR-005）；矩阵格子点击单独筛选（行级点击已覆盖，格子级交互不承诺）。

## 2. 业务规则

| 规则编号 | 规则名称 | 规则描述 |
|----------|----------|----------|
| FR004-R1 | 行列固定 | 行=EU/NA/ME/SEA/OTHER 固定顺序；列=可接/敏感/不可接/合计 |
| FR004-R2 | 计数口径 | 无信源筛选场景：格子=该大区展示条目按就严合并态计数（FR-003）；冲突条目计入就严列（BR-006） |
| FR004-R3 | 行点击 | 点击任一大区行 → 该行高亮 + 下钻区切换（FR-005）；空区（合计 0）也可点击 |
| GBR-007（引用） | 样例覆盖 | 样例数据必须五大区均有条目（QL-003），空区 0 分支由测试数据构造验证 |
