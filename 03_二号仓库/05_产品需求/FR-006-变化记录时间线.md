## 1. 功能概述

### 1.0 来源追溯表

| 追溯维度 | 来源编号/章节 |
|----------|----------------|
| 来源用户故事 | US-005（变化记录时间线） |
| 来源方案章节 | 全局方案定义 §4.3/GBR-002/GBR-003 |
| 来源页面 | PD-003 |
| 来源实体 | ENT-003 变化记录（append-only）、ENT-002/ENT-001（关联展示） |
| 来源规则 | 一号 BR-009/BR-010/BR-011 |

### 1.1 功能说明

按时间倒序展示规则状态变化时间线（时间/品类/大区/旧态→新态/信源依据/操作者），支持按品类与大区筛选；页面只读，任何写入只能来自 FR-008 修订流程的自动留痕。

### 1.2 前置条件

变化记录表可访问（含样例历史 ≥8 条，GBR-007）。

### 1.3 功能范围

**包含**：倒序时间线、品类/大区两维筛选、旧态→新态徽章展示、信源依据与操作者展示。
**不包含**：编辑/删除（GBR-003 禁止）；信源/状态筛选（US-005 范围外，不扩 scope）；群播报（REQ-007 非范围）。

## 2. 业务规则

| 规则编号 | 规则名称 | 规则描述 |
|----------|----------|----------|
| FR006-R1 | 排序 | 按 changed_at 倒序（精确到分钟） |
| FR006-R2 | 只读 | 页面不提供任何写操作入口；后端不提供编辑/删除 API（GBR-002/003，测试必测） |
| FR006-R3 | 关联完整性 | 每条变化记录必须能关联到存在的规则（含品类/大区/信源），无主记录不出现在时间线 |
| FR006-R4 | 筛选 | 品类（下拉）/大区（下拉）单选过滤，无组合限制 |
