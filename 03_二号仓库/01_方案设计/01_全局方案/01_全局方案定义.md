## 3. 状态计算规则（就严原则落地口径）——QL-001 落地

### 3.1 核心定义

1. **源规则**：一条源规则 = 品类 × 大区 × 信源 → 状态 + 依据（数据库最小单元）。
2. **展示条目**：展示条目 = 品类 × 大区（一个组合一条），状态 = 该组合下全部源规则的**就严合并态**。列表、矩阵、统计卡片、查询结果统一以展示条目为粒度。
3. **就严序**：`FORBIDDEN（不可接） > CONDITIONAL（敏感） > ACCEPTABLE（可接）`；合并态 = 就严序最高者。
4. **冲突判定**：同一展示条目下源规则存在 ≥2 种不同状态 → 该条目标注**多源冲突**；状态全部相同不算冲突。

### 3.2 信源筛选下的口径（定版）

- 无信源筛选：条目状态 = 就严合并态。
- 有信源筛选（选定单一信源）：只显示「该组合下存在该信源源规则」的条目，条目状态 = **该信源状态**（单源不合并，冲突标注隐藏）。
- 状态筛选：作用于「当前口径下的条目状态」（先算状态、后筛状态）。

### 3.3 QL-004「多源冲突」标注文案（本件定版）

| 元素 | 定版文案/样式 |
|------|---------------|
| 冲突徽标（状态徽章旁） | 文案「多源冲突」；样式：灰底描边小徽标（不占用三态色，避免与状态色混淆） |
| 冲突提示（悬停/展开头） | 「多个信源对该品类在此大区的判定不一致，已按就严原则（不可接 > 敏感 > 可接）展示最严状态，展开查看各信源原始判定」 |
| 展开行 | 按信源逐行展示：信源名 + 该信源状态徽章 + 依据文本 |
| 品名查询无命中文案（QL-005 语义锁死的视觉定版） | 标题「未命中结构化规则」+ 说明「建议转关务人工判断。当前规则库无该品名的结构化规则，看台不做推理判定。」 |

### 3.4 展示色（三态色定版）

| 状态 | 色值 | 用途 |
|------|------|------|
| 可接 ACCEPTABLE | 绿 `#16a34a` | 状态徽章/矩阵列头/卡片 |
| 敏感 CONDITIONAL | 橙 `#d97706` | 同上 |
| 不可接 FORBIDDEN | 红 `#dc2626` | 同上 |

状态展示用「色块+文字」双通道（色弱可读）。整体风格：浅色专业风（背景 `#f5f7fa`、卡片白、主色 `#2563eb`），不用深色主题。

## 4. 实体清单（字段级，对齐 OD 字典枚举）

### 4.1 ENT-001 品类 Category

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | 整数 | 是 | 主键 |
| name_zh | 文本(64) | 是 | 中文品类名，唯一 |
| name_en | 文本(128) | 是 | 英文品类名，唯一 |
| created_at | 时间 | 是 | 建档时间（首次登记时自动建档，US-006 AT-004） |

### 4.2 ENT-002 规则 Rule

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | 整数 | 是 | 主键 |
| category_id | 整数 | 是 | 外键→品类 |
| region | 枚举 | 是 | OD 字典 `region`：EU/NA/ME/SEA/OTHER（五大区） |
| source_type | 枚举 | 是 | OD 字典 `source_type`：POLICY/CUSTOMS/LOGISTICS/CARRIER/PORT |
| rule_status | 枚举 | 是 | OD 字典 `rule_status`：ACCEPTABLE/CONDITIONAL/FORBIDDEN |
| basis_text | 文本(500) | 是 | 依据文本（信源出处摘要，样例数据带「样例」标注） |
| note | 文本(200) | 否 | 备注（承接「海二适用性」标注习惯） |
| operator | 文本(32) | 是 | 登记人（v1.0.0 文本输入，无账号体系） |
| created_at / updated_at | 时间 | 是 | 登记/最近修订时间 |

约束：`(category_id, region, source_type)` 唯一——同组合重复登记引导走修订（FR-007 异常规则）。

### 4.3 ENT-003 变化记录 ChangeLog（append-only）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | 整数 | 是 | 主键 |
| rule_id | 整数 | 是 | 外键→规则（指向被修订的源规则） |
| old_status / new_status | 枚举 | 是 | 修订前后 rule_status |
| basis_text | 文本(500) | 是 | 本次修订依据 |
| operator | 文本(32) | 是 | 修订人 |
| changed_at | 时间 | 是 | 变化时间（默认当前时间，展示到分钟） |

约束：系统不提供编辑/删除入口（审计底线，版本验收锚点 2）；登记（新建规则）不产生变化记录。
