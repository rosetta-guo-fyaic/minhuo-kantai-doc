# 跨模块设计与冲突处理说明

## 1. 目录定位

`99_跨模块设计与冲突处理/` 是 `01_方案设计/` 的正式裁决与冲突留痕层。

本目录负责承接：

1. 模块边界冲突。
2. 实体归属冲突。
3. 属性口径冲突。
4. 状态、规则、导航和集成协同冲突。

## 2. 目录骨架

真实项目仓库中，建议按以下骨架落库：

```text
99_跨模块设计与冲突处理/
├── 00_全局裁决记录.md
└── 01_跨模块冲突清单.md
```

## 3. 模板仓库边界

1. 在模板仓库中，本目录只保留 `README.md`。
2. 冲突清单与裁决记录应在真实项目仓库中按需生成。
3. 不应在模板仓库中预置空白冲突正文。

## 4. 使用规则

1. 能在模块内部解决的事项，不应直接升级到本目录。
2. 一旦进入本目录，必须明确受影响的模块方案、全局专题和桥接清单。
3. 裁决完成后，必须回写受影响的正式真源层。
