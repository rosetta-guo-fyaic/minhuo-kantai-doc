# 全局方案定义说明

## 1. 目录定位

`02_全局方案定义/` 是 `01_方案设计/` 的跨模块正式收口层。

本目录负责承接：

1. 跨模块统一状态与生命周期。
2. 跨模块统一业务规则。
3. 统一的实体关系与属性口径。
4. 统一的字典、权限、导航和集成协同约束。

## 2. 目录骨架

真实项目仓库中，建议按以下骨架落库：

```text
02_全局方案定义/
├── 01_全局状态与生命周期定义.md
├── 02_全局业务规则定义.md
├── 03_全局业务实体关系与属性口径定义.md
├── 04_全局字典与枚举定义.md
├── 05_全局角色权限与数据范围定义.md
├── 06_全局导航与模块协同定义.md
└── 07_全局集成与外部协同定义.md
```

## 3. 模板仓库边界

1. 在模板仓库中，本目录只保留 `README.md`。
2. 各专题正文应在真实项目仓库中按需生成。
3. 不应在模板仓库中预置空白全局专题正文。

## 4. 事实归属

1. 同一跨模块事实只能在一个专题中正式裁决一次。
2. 模块内部事实不得反向覆盖本目录中的统一口径。
3. 若存在无法自动统一的事项，应升级到 `../99_跨模块设计与冲突处理/`。
