### 1.1 功能说明

定义全系统统一的状态计算口径：展示条目（品类×大区）的就严合并、冲突判定、信源筛选下的口径切换，以及「多源冲突」标注文案。所有展示（总览卡片/列表/矩阵/下钻/查询结果）必须消费同一实现，禁止各页自算。

### 1.2 前置条件

规则库可访问。

### 1.3 功能范围

**包含**：就严合并函数、冲突判定、单信源口径切换、冲突徽标与提示文案、无命中文案（PD-005 消费）。
**不包含**：第四态「建议转关务复核」（VDL §2 非范围）；可配置合并策略（预留建议见版本范围说明，v1.0.0 不做）。

## 2. 业务规则（计算口径，三/四号仓库以此实现与测试）

| 规则编号 | 规则名称 | 规则描述 |
|----------|----------|----------|
| FR003-R1 | 就严序 | FORBIDDEN > CONDITIONAL > ACCEPTABLE |
| FR003-R2 | 合并态 | 展示条目状态 = 其全部源规则中就严序最高者 |
| FR003-R3 | 冲突判定 | 同条目源规则状态去重后 ≥2 种 → conflict=true；全部相同 → false |
| FR003-R4 | 单信源口径 | 消费方选定单一信源时：无该信源源规则的条目不显示；显示条目状态=该信源状态，conflict 不标注 |
| FR003-R5 | 一致性 | FR-001/002/004/005/009 必须消费同一计算结果（同函数/同 API），任何页面不得自行实现 |

## 3. 展示定版（QL-004 在此关闭）

| 元素 | 定版 |
