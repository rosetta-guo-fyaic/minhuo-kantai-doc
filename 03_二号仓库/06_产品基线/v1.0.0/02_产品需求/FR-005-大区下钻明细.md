## 1. 功能概述

### 1.0 来源追溯表

| 追溯维度 | 来源编号/章节 |

| 来源规则 | GBR-001；一号 BR-007/BR-008 |

### 1.1 功能说明

矩阵下方明细区：选定大区后展示该大区全部展示条目（含信源/状态/依据/更新时间），支持信源/状态二次筛选与行展开源规则，聚焦单一市场的具体可接性规则。

### 1.2 前置条件

已通过 FR-004 选定大区（未选时显示引导语，不展示空表）。

### 1.3 功能范围

**包含**：选定大区明细列表、区内信源/状态二次筛选、行展开、更新时间列。
**不包含**：跨区聚合（BR-007）；目的港下钻；导出。

## 2. 业务规则

| 规则编号 | 规则名称 | 规则描述 |
|----------|----------|----------|
| FR005-R1 | 范围锁定 | 明细范围=矩阵选定大区（单一），不可跨区 |
| FR005-R2 | 字段集 | 列=品类（中英）/信源/状态/依据/更新时间，与 PD-001 列表同字段集（BR-008），仅范围与多「信源列」 |
| FR005-R3 | 二次筛选口径 | 信源/状态筛选复用 FR-002 R2/R3 同一规则（选定信源→单源口径） |
| FR005-R4 | 未选引导 | 未选大区时显示引导语而非空表（区分「未选择」与「无数据」） |
