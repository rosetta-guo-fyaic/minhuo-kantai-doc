## 3. 区块说明

### 3.1 三态统计卡片（FR-001）

1. 三张卡片：可接 N1 / 敏感 N2 / 不可接 N3，卡片色 = 三态色，数字为**展示条目**（品类×大区，就严合并后）计数，N1+N2+N3 = 展示条目总数。
2. 卡片数字与筛选联动（FR-002 筛选生效时按当前筛选结果重算）。
3. 规则库为空：三卡显示 0，列表区显示空态。

### 3.2 筛选区（FR-002）

| 筛选器 | 选项 | 口径 |
|--------|------|------|
| 大区 | 全部/欧洲/北美/中东/东南亚/其他 | 单选，过滤展示条目 |
| 信源 | 全部/国家政策/海关/头部物流/船司/目的港 | 单选；选定后条目状态=该信源状态（全局方案 §3.2） |
| 状态 | 全部/可接/敏感/不可接 | 作用于当前口径下条目状态 |
| 重置 | — | 恢复全部/全部/全部 |

### 3.3 品类规则列表（FR-002 + FR-003）

1. 行 = 展示条目（品类×大区），默认按品类名排序（中文拼音序，同品类多行相邻）。
2. 列：品类（中文名+英文名）、大区、状态徽章、冲突徽标（仅冲突条目）、依据摘要（合并态对应最严源规则的依据，截断 40 字）、展开箭头。
3. 展开行：该组合下全部源规则逐条「信源名 + 状态徽章 + 依据全文」；信源筛选生效时高亮所选信源行。
4. 冲突条目：状态 = 就严态 + 「多源冲突」徽标；悬停徽标显示全局方案 §3.3 定版提示文案。
