# To-Be 流程说明

## 1. 目录定位

`02_To-Be流程/` 用于记录本项目 To-Be 流程图、流程说明、流程评审稿和流程确认稿。

该目录属于项目级业务输入沉淀区，不替代方法论中的公共流程规则。

## 2. 主要承载内容

建议优先形成以下内容：

1. 目标业务流程主线
2. 关键角色参与步骤
3. 关键输入、输出、审批和例外分支
4. 流程评审意见与确认结论

## 3. 推荐使用依据

建议优先参照：

1. `<TOOL_REPO_ROOT>/07_公共模板库/01_OD工作模板/02_To-Be流程梳理模板.md`
2. `<TOOL_REPO_ROOT>/07_公共模板库/01_OD工作模板/标准业务流程登记表模板.md`
3. `<TOOL_REPO_ROOT>/06_工作规范/02_OD工作规范/README.md`
4. `<TOOL_REPO_ROOT>/06_工作规范/02_OD工作规范/附件-模型-流程分类与分层定义.md`

## 4. 使用规则

1. 流程应以业务目标和角色协作为主，不要提前写成系统页面方案
2. 每条正式流程建议同时标注横向分类、属性分类和纵向层级
3. 流程中的待确认节点、例外路径和跨部门责任边界应显式标注
4. 若流程已进入治理细化阶段，可补充流程来源与边界表、流程步骤主表、流程治理与检查表
5. 零号仓库和一号仓库后续如引用流程，应回看本目录中的确认口径
