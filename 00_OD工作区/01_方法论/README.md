# 方法论说明

## 1. 目录定位

`01_方法论/` 用于记录本项目在 OD 方法论工作体系下形成的项目方法论输入、适配说明和项目执行原则。

本目录的上位理解依据不是 `<TOOL_REPO_ROOT>/09_DIC研发方法论/`，而是：

1. `<TOOL_REPO_ROOT>/06_工作规范/02_OD工作规范/方法论-方法论工作体系方法论（道法术器_制度完整版V1）.md`
2. `<TOOL_REPO_ROOT>/07_公共模板库/01_OD工作模板/01_项目方法论采用说明模板.md`
3. `<TOOL_REPO_ROOT>/07_公共模板库/01_OD工作模板/附件-模板-方法论主文件模板.md`

## 2. 主要承载内容

建议优先形成以下内容：

1. 本项目采用的方法论范围
2. 项目方法论输入的适配说明
3. 上游规则来源、方法边界和项目裁剪原则
4. 项目执行中的特殊约束或补充说明
5. 如已成熟，可补方法论主文件或其附件草稿

## 3. 推荐使用依据

建议优先参照：

1. `<TOOL_REPO_ROOT>/06_工作规范/02_OD工作规范/README.md`
2. `<TOOL_REPO_ROOT>/06_工作规范/02_OD工作规范/方法论-方法论工作体系方法论（道法术器_制度完整版V1）.md`

4. `<TOOL_REPO_ROOT>/07_公共模板库/01_OD工作模板/附件-模板-方法论主文件模板.md`

## 4. 使用规则

1. 这里只写“本项目采用什么、怎么适配、哪些规则必须承接”
2. 不在本目录中复制 `<TOOL_REPO_ROOT>/09_DIC研发方法论/` 的研发方法正文
3. 若项目方法输入已成熟，可以按 OD 方法论模板继续沉淀主文件或附件
4. 若项目阶段定义、门禁或适配策略有变化，应回写本目录主文件
