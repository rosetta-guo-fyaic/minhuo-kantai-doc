# 权限矩阵说明

## 1. 目录定位

`04_权限矩阵/` 用于记录本项目角色权限、审批权限、数据范围和项目级 DoA。

它负责在项目前置阶段先明确权限边界和审批主线，为零号、一号、二号仓库后续正式设计打基础。

## 2. 主要承载内容

建议优先形成以下内容：

1. 角色与权限初步对应关系
2. 审批权限和授权边界
3. 数据范围与可见性原则
4. 需要后续产品设计进一步细化的权限事项

## 3. 推荐使用依据

建议优先参照：

1. `<TOOL_REPO_ROOT>/07_公共模板库/01_OD工作模板/04_权限矩阵模板.md`
2. `<TOOL_REPO_ROOT>/07_公共模板库/01_OD工作模板/模板-产品经理开发引用-权限模板.md`
3. `<TOOL_REPO_ROOT>/06_工作规范/05_产品设计规范/06_权限审计与安全设计规范.md`
4. `<TOOL_REPO_ROOT>/06_工作规范/02_OD工作规范/README.md`

## 4. 使用规则

1. 本目录记录的是项目级初步权限共识，不替代二号仓库的正式权限设计真源
2. 角色、审批、数据范围应尽量结构化描述，不要只写模糊结论
3. 对高风险动作、SoD、DoA、例外授权应尽量前置识别
4. 对仍需进一步细化的权限事项，应显式标记为待设计或待确认
5. 若需要向产品经理输出开发引用输入，可补充高风险动作控权表
