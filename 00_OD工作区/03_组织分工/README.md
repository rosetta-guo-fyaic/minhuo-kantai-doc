# 组织分工说明

## 1. 目录定位

`03_组织分工/` 用于记录本项目组织结构、角色职责、分工边界和协作关系。

它负责在项目正式启动前，先把“谁负责什么、谁参与什么、谁决策什么”讲清楚。

## 2. 主要承载内容

建议优先形成以下内容：

1. 项目参与角色清单
2. 各角色职责和边界
3. 关键协作关系和交接关系
4. 决策、升级和例外处理机制

## 3. 推荐使用依据

建议优先参照：

1. `<TOOL_REPO_ROOT>/07_公共模板库/01_OD工作模板/03_组织分工模板.md`
2. `<TOOL_REPO_ROOT>/07_公共模板库/01_OD工作模板/模板-产品经理开发引用-组织模板(1)(2).md`
3. `<TOOL_REPO_ROOT>/06_工作规范/02_OD工作规范/README.md`

## 4. 使用规则

1. 建议显式区分业务、OD、产品、技术、实施、测试、运维与 AI 协同角色
2. 不要用泛化称谓替代实际责任边界，例如只写“项目组负责”
3. 若同一事项存在主责、协助、审核、审批关系，应分别写清楚
4. 若后续需要给产品经理做结构化输入，可补充“部门与岗位清单表”和“流程职责分工表”
