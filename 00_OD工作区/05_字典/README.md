# 字典说明

## 1. 目录定位

`05_字典/` 用于记录本项目补充字典、项目枚举和标准词典引用登记。

标准词典真源位于 `<TOOL_REPO_ROOT>/04_标准词典库/`。本目录只允许记录项目级补充与引用，不替代标准词典真源。

## 2. 主要承载内容

建议优先形成以下内容：

1. 项目引用的标准词典清单
2. 项目级补充术语和枚举
3. 术语别名、冲突项和待统一项
4. 后续需提交到标准词典库统一治理的候选项

## 3. 推荐使用依据

建议优先参照：

1. `<TOOL_REPO_ROOT>/04_标准词典库/README.md`
2. `<TOOL_REPO_ROOT>/07_公共模板库/01_OD工作模板/05_项目字典引用与补充清单模板.md`
3. `<TOOL_REPO_ROOT>/07_公共模板库/01_OD工作模板/附件-模板-字典正式词条卡模板.md`
4. `<TOOL_REPO_ROOT>/07_公共模板库/01_OD工作模板/附件-模板-联盟字典正式词条总表模板.md`
5. `<TOOL_REPO_ROOT>/06_工作规范/02_OD工作规范/README.md`
6. `<TOOL_REPO_ROOT>/06_工作规范/02_OD工作规范/附件-模型-字典顶层域与子域结构.md`

## 4. 使用规则

1. 标准术语优先引用 `<TOOL_REPO_ROOT>/04_标准词典库/`，不要在本目录重造真源
2. 项目补充项应显式标注来源、适用范围和是否需升格为标准词典
3. 若不同材料中同一术语存在多种叫法，应在本目录先做统一登记
4. 若项目字典治理已较成熟，可按顶层域与子域结构继续沉淀词条卡和总表草稿
