## 1. 核心术语

| 术语 | 本项目定义 | 原始材料出处/备注 |
| --- | --- | --- |
| 敏货 | 敏感货物统称：被外部信源施加限制、需要审核或禁止承接的货物 | 材料中「敏感货/审核货」混用，本字典统一为「敏货」 |
| 可接 | 当前信源规则下可正常承接 | M1 三态之一 |
| 敏感（条件接） | 有条件承接：需附加条件（证明文件/包装要求/额外费用）或人工评估 | 对应材料「附加条件/审核货」 |
| 不可接 | 信源明确禁止承接（负面清单） | 负面清单只能判「不能接」（M2） |
| 建议转关务复核 | 规则冲突或覆盖不足时的第四展示态（非数据态） | M1 |
| 品类 | 敏货规则的作用对象；v1.0.0 用中文品类名 + 英文名对照 | 如「锂电池/Power Bank」 |
| 大区 | 地区聚合维度：欧洲/北美/中东/东南亚/其他 | OD 收敛 OD-03 |
| 信源 | 规则来源五类：国家政策/海关/头部物流/船司/目的港 | M3 |
| 变化记录 | 规则状态旧值→新值的留痕（时间/操作者/依据） | M6 审计底线 |

## 2. 枚举登记（供数据模型直接引用）

- `rule_status`: `ACCEPTABLE`(可接) / `CONDITIONAL`(敏感) / `FORBIDDEN`(不可接)
- `source_type`: `POLICY`(国家政策) / `CUSTOMS`(海关) / `LOGISTICS`(头部物流) / `CARRIER`(船司) / `PORT`(目的港)
- `region`: `EU`(欧洲) / `NA`(北美) / `ME`(中东) / `SEA`(东南亚) / `OTHER`(其他)
