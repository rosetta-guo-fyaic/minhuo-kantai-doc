# 已确认需求说明

`02_已确认需求/` 用于沉淀已确认需求的专题整理材料，是 `00_需求清单.md` 的专题展开层。

## 1. 目录定位

本目录适合承接以下场景：

1. 某一业务域下已有多条需求确认完成，需要按主题集中展开
2. 某一模块的规则、边界、例外较多，不适合只保留在需求清单主表一行中
3. 需要在进入 `03_需求分析/` 前，先形成较稳定的确认专题稿

## 2. 与其他产物的关系

1. 它来源于 `00_需求清单.md` 中已确认的需求
2. 它可以引用 `01_待确认需求/` 的关闭结论
3. 它是 `03_需求分析/` 的上游输入之一
4. 它不替代 `00_需求清单.md`
5. 它不直接替代用户故事和 URD

## 3. 产物形式

本目录不在模板仓中预置具体专题文件。

真实项目仓库中，建议按以下方式按需生成：

1. `AC-01_某业务域已确认需求.md`
2. `AC-02_某模块已确认需求.md`
3. `AC-03_某流程主题已确认需求.md`

对应模板真源：

1. `<TOOL_REPO_ROOT>/07_公共模板库/03_一号仓库模板/08_已确认需求专题模板.md`

## 4. 使用规则

1. 每份专题文件都应明确承接哪些 `REQ-*`
2. 每份专题文件都应写清确认后的规则、边界、例外和限制条件
3. 若仍存在未关闭事项，应显式回指 `01_待确认需求/02_待确认清单.md`
4. 专题文件只展开已确认内容，不承载未坐实结论
