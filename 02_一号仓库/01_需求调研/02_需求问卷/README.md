# 需求问卷说明

## 1. 目录定位

`02_需求问卷/` 是一号仓库需求调研阶段的调研准备层。

它用于在正式调研开始前，沉淀“要问什么、问谁、验证什么、希望得到什么结果”。

一句话理解：

这里解决的是“调研前准备怎么做”，不是“调研结果怎么记录”。

## 2. 应承接的内容

本目录主要承接：

1. 需求问卷
2. 访谈提纲
3. 业务主题问题清单
4. 调研前待验证假设
5. 调研目标与预期输出说明

## 3. 与相邻目录的边界

1. `01_原始资料/`
   - 放业务侧直接提供的原件
   - 不替代问卷准备件
2. `02_需求问卷/`
   - 放调研前准备件
   - 是产品经理主动设计的输入
3. `03_调研记录/`
   - 放调研过程中形成的记录
   - 不是调研前准备件
4. `04_调研整理（md）/`
   - 放对问卷、记录和原件的结构化整理稿

## 4. 使用规则

1. 本目录只放调研前准备件，不放调研后的纪要、结论或正式需求真源。
2. 同一轮调研如既有问卷又有访谈提纲，可按主题分别建文件，不强行合并。
3. 每份问卷或提纲都应尽量写明：
   - 调研目标
   - 调研对象
   - 核心问题
   - 待验证假设
   - 预期输出
4. 问卷回收结果、访谈实际回答和调研观察，应进入 `03_调研记录/` 或 `04_调研整理（md）/`，不要回写在本目录当作结果留痕。

## 5. 文件命名建议

建议优先使用以下命名方式：

1. `需求问卷_主题_日期.md`
2. `访谈提纲_主题_日期.md`
3. `调研问题清单_主题_日期.md`
