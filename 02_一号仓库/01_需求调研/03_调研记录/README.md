# 调研记录说明

## 1. 目录定位

`03_调研记录/` 是一号仓库需求调研阶段的调研过程留痕层。

它用于承接访谈纪要、会议记录、现场调研记录、专项沟通记录和问卷回收过程记录。

一句话理解：

这里解决的是“调研过程中实际发生了什么、谁说了什么”，不是“最终结论是什么”。

## 2. 应承接的内容

本目录主要承接：

1. 访谈纪要
2. 会议记录
3. 现场调研记录
4. 问卷回收过程记录
5. 专项沟通记录

## 3. 与相邻目录的边界

1. `02_需求问卷/`
   - 放调研前的问题设计和准备件
2. `03_调研记录/`
   - 放调研过程材料
3. `04_调研整理（md）/`
   - 放对调研记录的结构化整理稿
4. `05_调研结论与待转确认项/`
   - 放从多份记录中归纳出的初步结论与待确认事项

## 4. 使用规则

1. 一次调研活动原则上形成一份独立记录，不要把多个调研活动长期混在同一份文件里。
2. 本目录重点保留“过程事实”和“原始表达”，不要直接把调研记录写成结论稿。
3. 调研记录中的观点、痛点、问题和建议，后续应再进入 `04_调研整理（md）/` 做结构化整理。
4. 若记录中已经显露出待确认事项，也应先保留在过程记录中，再在整理或结论层统一转出。

## 5. 编号与命名建议

1. 建议使用 `SRV-*` 作为调研记录编号。
2. 建议命名方式为：`SRV-YYYYMMDD-XXX_主题.md`
3. `SRV-*` 仅用于调研记录与来源追溯，不作为正式需求对象编号。
