# 原始资料说明

## 1. 目录定位

`01_需求调研/01_原始资料/` 是一号仓库的原件承接区。

这里用于存放客户或业务侧直接提供的原始材料，包括但不限于：

1. Excel、Word、PPT、PDF
2. 流程图、截图、表单和附件
3. 会议纪要原件、录音、图片
4. 未经产品经理改写的业务说明材料

一句话理解：

这里解决的是“原始资料从哪里来”，不是“需求如何被确认或分析”。

## 2. 与相邻目录的关系

- `01_原始资料/`
  - 保留原件，强调保真存档
- `02_需求问卷/`
  - 承接调研前的问题设计和问卷准备
- `03_调研记录/`
  - 承接访谈、会议和现场调研记录
- `04_调研整理（md）/`
  - 对原件做转写、摘录和结构化整理

原件不要直接跳过调研整理层进入需求确认或需求分析层。

## 3. 使用规则

1. 原始材料优先落在本目录，不要直接写进正式需求分析文档
2. 本目录内容以保真存档为主，不要求统一模板化表达
3. 不在本目录直接写正式 `REQ`、`US`、`URD`
4. 如需分析、总结或归纳，应转入 `04_调研整理（md）/`
5. 同一份资料若既有原件又有整理稿，应显式说明来源关系
6. 若原件来自 `00_OD工作区/` 之外的补充访谈、会议或业务补件，应在整理稿中说明补入原因

## 4. 文件组织建议

1. 建议尽量保留原文件名，不对业务侧原件做语义改写
2. 如需补充识别信息，建议使用：`来源方_主题_日期.扩展名`
3. 不要在本目录人为拆分、改写或重排原件内容
