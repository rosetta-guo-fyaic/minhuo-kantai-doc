# 调研结论与待转确认项说明

## 1. 目录定位

`05_调研结论与待转确认项/` 是一号仓库需求调研阶段的调研收口桥接层。

它用于在调研结束后，对 `04_调研整理（md）/` 中的信息做一轮“初步收口”，把已经形成的结论和仍待确认的事项整理出来，再转入 `02_需求确认/`。

一句话理解：

这里解决的是“调研结果如何进入正式确认层”，不是“长期维护第二套确认主表”。

## 2. 应承接的内容

本目录重点承接：

1. 调研阶段初步结论
2. 调研发现的问题清单
3. 建议转入 `02_需求确认/00_需求清单.md` 的候选需求
4. 建议转入 `02_需求确认/01_待确认需求/02_待确认清单.md` 的确认事项

## 3. 与 `02_需求确认/` 的边界

1. 本目录不是长期正式真源。
2. 本目录中的内容最终必须转入 `02_需求确认/` 的正式主表或主清单。
3. 若某项已经正式进入：
   - `00_需求清单.md`
   - `02_待确认清单.md`
   - `02_需求确认/` 下的辅助材料
   则本目录只保留桥接记录和回写状态，不再长期并行维护同一内容。
4. 本目录不直接进入 `03_需求分析/`，所有正式分析内容都应先完成 `02_需求确认/` 收口。

## 4. 使用规则

1. 本目录中的文档应以“调研收口稿”或“转确认桥接稿”为主，不应铺设大量长期维护的主文件。
2. 可以沉淀“已明确结论”和“待确认事项”，但不应直接把未确认内容写成正式事实。
3. 调研阶段形成的桥接稿，应尽快回写到 `02_需求确认/` 对应主表或清单。
4. 若某项长期停留在本目录而未进入 `02_需求确认/`，应视为收口未完成。

## 5. 文件组织建议

建议控制为以下两类：

1. `00_调研结论总览.md`
2. `主题_待转确认项.md`
