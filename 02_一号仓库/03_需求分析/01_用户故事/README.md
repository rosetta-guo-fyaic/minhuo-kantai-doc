# 用户故事说明

`01_用户故事/` 用于存放一号仓库正式用户故事文档。

这里的用户故事应基于已完成需求确认的需求项编写，并可被二号仓库正式方案设计直接承接。

## 1. 目录定位

本目录是 `03_需求分析/` 下的单故事真源层。

它负责：

1. 把 `REQ-*` 拆成单条 `US-*` 正式文档
2. 补齐角色、目标、场景和验收标准
3. 为二号仓库方案设计提供稳定、可追溯的故事输入

它不是：

1. 待确认事项区
2. 方案设计区
3. 页面原型区

## 2. 文件规则

1. 真实项目仓库中按需生成 `US-*.md`
2. 每个文件只承载一个用户故事
3. 应优先基于 `<TOOL_REPO_ROOT>/07_公共模板库/03_一号仓库模板/04_用户故事模板.md` 生成
4. 每个 `US-*` 都必须回指来源 `REQ-*`

## 3. 与相邻目录的边界

1. `02_需求确认/`
   - 负责确认和收口
   - 不直接替代用户故事正文
2. `02_需求补充材料/`
   - 负责跨故事共用规则、边界和口径
   - 不替代单故事主体
3. `03_URD.md`
   - 负责项目级正式汇总
   - 不替代单故事独立正文

## 4. 下游承接

1. 本目录属于二号仓库 `01_方案设计/` 的直接正式输入
2. 每条用户故事应支持继续承接为 `USS-*`
3. 未完成确认或缺少追溯关系的 `US-*` 不应进入正式承接范围
